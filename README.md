# Shanghai Phrases · ภาษาเซี่ยงไฮ้
Live: https://piyaster11.github.io/shanghai-phrases/

Everyday Mainland Mandarin (Simplified Chinese) for visiting Shanghai, with pinyin, English, Thai, notes and audio, plus a few Shanghainese (沪语) phrases (no audio, approximate romanization).
- Edit `data/phrases_src.json`, run `python3 scripts/build.py` (needs `pip install gTTS edge-tts`).
- Voice: edge-tts `zh-CN-XiaoxiaoNeural` if reachable, else gTTS `zh-CN`.
- After changing app.js/style.css, bump `?v=` in index.html and `VER` in app.js.
